DeepSeek Harness 便携版 - 使用说明
====================================

一、这是什么
  免安装、可移植的 DeepSeek Harness 桌面版。内嵌 Node.js 运行时和
  dsh 全部依赖，任意 Windows 电脑双击即可运行，无需安装 Node.js。

二、怎么用
  1. 将整个文件夹复制到任意位置（U盘、移动硬盘、桌面均可）。
  2. 双击“启动-DeepSeek-Harness.cmd”。
  3. 打开浏览器访问 http://127.0.0.1:3080
  4. 在设置中填入 DeepSeek API Key 后即可使用。
  5. 关闭弹出的命令行窗口即停止。

  命令行用法：
    dsh.cmd web                               启动 Web 界面
    dsh.cmd --profile headless "问题"         无界面执行一个任务
    dsh.cmd plugin --profile web add <包名>   安装插件

  安装插件：
    插件是声明了 dsh.bundle 的 npm 包，装到 data\profiles\<name>\，安装后
    重启 Web UI 生效。若提示 ERR_PNPM_IGNORED_BUILDS，编辑
    data\profiles\web\pnpm-workspace.yaml，把 allowBuilds 下对应包改为 true
    后重新安装即可；提示缺少 Visual Studio 属可选原生模块编译失败，一般
    不影响使用。

  桌面管理器（HarnessManager.exe）：
    双击 HarnessManager.exe 打开桌面管理器(原生窗口,Win10/11 自带
    WebView2;无 WebView2 时自动用浏览器打开)。功能:仪表盘(版本/data
    占用/运行中服务检测与停止/快捷启动)、插件管理(安装/移除/禁用/
    启用 bundle)、升级管理(检查并一键升级 dsh,只动 app\,data\ 不受
    影响)、数据与备份(data\ 一键打包 zip,恢复分合并/彻底两种,可
    删除备份,settings.yaml 编辑)。
    并行任务建议直接在 dsh Web UI 中创建多个会话/Agent,无需多实例。

三、数据都在哪里
  全部数据保存在本文件夹的 data\ 目录：
    data\settings.yaml      设置
    data\.credentials.yaml  API Key 等凭据
    data\.agents\           技能（skills）
    data\profiles\          各配置方案与插件
    data\sessions\ 等       会话历史
  把整个文件夹复制到别的电脑，配置和数据直接可用。

四、如何升级
  官方 dsh 发布新版本后：
  - 文件夹版：双击“升级-便携版.cmd”，联网自动更新，data\ 数据原样保留。
  - 单文件 exe 版：需要在构建机上重新构建（pwsh -ExecutionPolicy Bypass
    -File build-all.ps1，自动保留 data\）。
  升级前建议把 data\ 文件夹复制一份备份。

五、常见问题
  - 端口被占用：先运行 Stop-DeepSeek-Harness.cmd，或用 dsh.cmd web --port 3081
  - 想重置：删除 data\ 文件夹
  - 杀毒软件提示：便携版不写注册表、不改系统，可放心使用
  - 管理器中点"打开 data 目录"没反应：系统资源管理器异常（Windows 11 的
    explorer 进程泄漏，反复使用文件夹选择框后可能堆积几十个 explorer 进程，
    拖垮系统打开目录的通道）。重启电脑，或运行
    taskkill /f /im explorer.exe && start explorer.exe 恢复。新版管理器会自动
    检测到异常并改用命令行窗口打开目录，文件夹选择框也不再产生泄漏。
